# 「铁路信号台」设计系统

> 目标：把 TraceDot 票面工坊的视觉语言，落到本项目的原生 HTML/CSS/JS 上。
> 令牌：`assets/design/tokens.css`；图标：`assets/design/icons.svg`；截图：`assets/design/screenshots/`。

## 1. 设计原则

1. **像一张纸，不像一块玻璃**：实色卡片、发丝线、纸面阴影；禁止 `backdrop-filter`、禁止大面积半透明模糊。
2. **信号绿只做“动作”**：主按钮、选中态、焦点、进度；不要把所有装饰都染绿。
3. **信息按票据顺序排**：预览 → 款式 → 字号 → 动作 → 表单 → 导入；手机上也保持这个心智顺序。
4. **静态背景**：渐变、斜纹、聚光都是静态图层；不做背景动画。
5. **24 网格线性图标**：1.7–1.8 描边、圆角接头、`currentColor`；禁止 emoji 当图标。
6. **触控优先**：手机端所有可点区域 ≥44×44；桌面端 32–40 高。
7. **离线优先**：字体、图标、PDF 引擎都不依赖 CDN；Nunito Sans 可选自托管。

## 3. 字体

```css
--td-font-ui: "Nunito Sans", "PingFang SC", "HarmonyOS Sans SC",
              "Noto Sans SC", "Microsoft YaHei", sans-serif;
--td-font-mono: "JetBrains Mono", ui-monospace, ...;
```

- **Nunito Sans**：仅 Latin/数字。OFL 许可，可自托管 woff2；不联网加载。若不引入，回退到系统 sans，视觉差异可接受。
- **中文**：PingFang SC → HarmonyOS Sans SC → Noto Sans SC → Microsoft YaHei。
- **票面**：Times New Roman + 中文回退；票号 Arial（见 `ticket-template-spec.md`）。
- **营销站**用的是 Plus Jakarta Sans + Noto Sans SC + JetBrains Mono；工坊不跟随，避免多一套字体。
- 字号阶：10/11/12/13/14/16/18/22/28/34；正文 13–14，表单 13，标题 18–22，票面按画布。
- 行高：UI 1.5；表单 1.4；票面不设行高（逐行定位）。

## 4. 图标

- 文件：`assets/design/icons.svg`，30 个 `<symbol>`，`viewBox="0 0 24 24"`。
- 用法：把 sprite 内联到页面顶部，`<svg class="ic"><use href="#i-ticket"/></svg>`。
- 尺寸：16（行内）/18（按钮）/20（卡片标题）/24（空状态）。
- 线条：`stroke="currentColor"`，`stroke-width="1.8"`，`stroke-linecap="round"`，`stroke-linejoin="round"`；实心只用于小圆点/状态点。
- 禁止：用 emoji、用多色图标、用 12px 以下描边图标、给图标加滤镜。

## 5. 布局

### 5.1 桌面 ≥1024

```text
┌──────────────────────────────────────────────────────────────┐
│ topbar 56px：品牌 / 页面名 / 状态 / 主题 / 帮助              │
├───────────────────────────────────────────┬──────────────────┤
│ 左列 65%                                   │ 右列 35%         │
│ ┌───────────────────────────────────────┐ │ 行程信息         │
│ │ 预览卡：车票居中，纸面背景，阴影       │ │ 票号/检票口      │
│ │ 8 款缩略图横排                         │ │ 始发/到达/拼音   │
│ │ 字号 / 粗细 / 中英数字字体             │ │ 车次/席别/日期   │
│ │ 细节调整 / 导出 / 导入珍藏册 / 清除    │ │ 车厢/座位/铺位   │
│ ├───────────────────────────────────────┤ │ 票价/证件/姓名   │
│ │ PDF 导入（50%）｜ 纸质票识别（50%）    │ │ 附加信息/备注    │
│ └───────────────────────────────────────┘ │ 二维码           │
└───────────────────────────────────────────┴──────────────────┘
```

- 页面最大宽 1440，左右 padding 24；左列 `minmax(0,1.75fr)`，右列 `minmax(360px,1fr)`，gap 20。
- 预览卡最小高 420；车票按容器宽度等比缩放，最大 809×509，不放大超过 1x（避免糊）。
- 模板条 8 个 chip，每个 88×56，选中 2px 主色 + 右上角 check。
- 表单两列（字段对），窄字段（车厢/座位/铺位）三列。

### 5.2 平板 768–1023

- 单列：预览 → 模板/字体/动作 → 表单 → PDF；
- 表单仍两列；预览卡宽度 100%，最大 720。

### 5.3 手机 <768

- 单列，顺序：预览 → 模板横滑 → 字号/字重 → 字体方案 → 主动作 → 表单 → PDF；
- 底部固定快捷导航 5 项：预览 / 行程 / 乘客 / 导入 / 识别；高度 56 + safe-area；
- 主按钮全宽 44 高；模板 chip 64×40；
- 表单单列；日期/时间并排；车厢/座位/铺位三列；
- 不允许横向滚动；长站名/长姓名在票面内缩排，不撑破页面。

## 6. 组件

### 6.1 卡片

```css
background: var(--td-surface);
border: 1px solid var(--td-border);
border-radius: var(--td-radius-lg); /* 14 */
box-shadow: var(--td-shadow-md);
```

标题行：图标 20 + 标题 16/600 + 右侧元信息（chip/状态点）。卡片内边距 16–18。

### 6.2 输入

- 高 40；圆角 10；底 `#FFFEFB`；边 `#D8CCB6`（比卡片边更深，形成“纸面凹槽”）。
- focus：边 `#3F9471` + 3px `rgba(63,148,113,.14)` 外圈。
- 错误：边 `#D9383E` + 下方 12px 错误文案；不要只靠颜色，配 `i-warn`。
- 只读/禁用：底 `#F0F8F3`，文字 `#84A08F`。

### 6.3 按钮

| 类型 | 样式 |
| --- | --- |
| primary | 信号绿底、白字、2px 压边阴影；高 40（手机 44） |
| secondary | 白底、1px 边、深绿字 |
| ghost | 透明底、无边框、hover 浅绿 |
| danger | 白底红字红边；仅用于清除/删除 |
| icon | 36×36，圆角 10，hover 浅绿 |

### 6.4 模板 chip

- 88×56，圆角 10，白底，1px 边；
- 内含缩略图（cover）+ 底部 11px 标签；
- 选中：2px 主色边、右上角 16px 实心 check、阴影提升；
- hover：translateY(-1px)；active：回弹 0。

### 6.5 滑块

- 轨道 4px，`#E0EFE6`；已选 `#3F9471`；拇指 16px 白底 + 2px 主色边。
- 右侧显示当前值（`100%` / `500`），等宽数字。
- 键盘：左右键 ±1，Home/End 到边界。

### 6.6 弹窗 / Toast / 进度

- 免责声明：640px，遮罩 `rgba(38,32,20,.52)`，标题 22/700，正文 15.5/2.0；确认按钮 3 秒倒计时；拒绝则关闭页面/回到积分页。
- 导出询问背面：480px，两个按钮“否，直接导出”“是，制作背面”。
- Toast：底部居中（手机在底部导航上方），2.4s 自动消失，最多 3 条。
- 进度：全屏半透明遮罩 + 卡片 + 进度条 + `已完成/总数` + 取消；完成显示“导出成功”。

## 7. 动效与性能

- 时长：140/200/320ms；缓动 `cubic-bezier(.22,1,.36,1)`；不要弹跳超过 1 次。
- 只动 `transform` / `opacity`；不动 `width/height/top/left`。
- **禁止**：`backdrop-filter`、`filter: blur()` 大区域、背景无限动画、每帧 `getImageData`。
- 预览重绘用 `requestAnimationFrame` 合并；二维码按内容缓存；底图只 decode 一次。
- 导出用离屏 canvas，避免阻塞预览；大图导出前显示进度。
- `prefers-reduced-motion: reduce` 时全部瞬时。

## 8. 可访问性

- 正文对比度 ≥4.5:1；大字号 ≥3:1；主色文字只用 `#2E7455`。
- 所有输入有 `<label for>`；图标按钮有 `aria-label`；状态有 `aria-live`。
- 焦点可见：2px `#3F9471` + 2px offset；不要 `outline:none` 不留替代。
- 弹窗焦点陷阱，Esc 关闭（免责声明除外，必须明确选择）。
- 触控目标 ≥44×44；手机底部导航考虑 `env(safe-area-inset-bottom)`。
- 颜色不是唯一信息：错误/选中同时用图标或文字。
