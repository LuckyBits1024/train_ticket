# Rail Memory v2 · 八款票面底图

本目录是「纪念车票」新模板体系的素材与元数据，供 Web 车票工坊与 Python CLI 共用。

## 文件

| 路径 | 用途 |
| --- | --- |
| `front/` | 八款正面底图（已去除全部可变文字，仅保留底纹、列车图案、虚线框、底部色带） |
| `thumbs/` | 240×151 款式选择缩略图 |
| `reference/` | 按目标版式渲染的参考图，用于视觉走查和回归对比 |
| `manifest.json` | 款式、画布尺寸、底图偏移、排版微调、素材哈希 |
| `NOTICE.md` | 来源、权利与使用限制，务必阅读 |

## 使用约定

1. **不要把文字烧进底图**。所有可变字段、固定文案、箭头、二维码都由渲染器绘制。
2. **按 1x 逻辑坐标绘制，再整体缩放**。逻辑画布见 `manifest.json` 的 `canvas`；导出宽度默认 2x（蓝 1618 / 红 1600），不得超过 3x。
3. `blue-etch*` 的底图大于画布，必须 `cover` 等比铺满并居中裁切；其余款式 1:1 贴图。
4. 红票家族有 `dx=10, dy=20` 的整体偏移；蓝票家族为 `0,0`。在此基础上再应用每款的 `adjust`。
5. 底图是扫描/版画质感素材，**不要**做锐化、对比度拉伸或重新压缩；导出用 PNG。
6. 字体不随包分发。Web 用系统字体栈；Python 用系统字体路径，缺失时按错误提示指定。

## 校验

```bash
shasum -a 256 assets/ticket-template/v2/front/*
```

哈希以 `manifest.json` 中的 `sha256` 为准。参考图仅用于对比，不是运行时素材。
